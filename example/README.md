# SSD1322 OLED Examples

This directory contains examples for the SSD1322 OLED display library.

## Available Examples

### DMA MIDI Example
Located in: `dma_midi_example/`

A complete PlatformIO project that demonstrates how to efficiently update an SSD1322 OLED display using DMA while simultaneously processing MIDI-like data streams. This example shows how to maintain high-performance graphics updates while keeping the CPU free for time-critical operations.

### To run any of these examples:

1. Navigate to the specific example folder
2. Open the folder in PlatformIO
3. Build and upload to your Teensy/Arduino device
4. Follow specific instructions in each example's README
